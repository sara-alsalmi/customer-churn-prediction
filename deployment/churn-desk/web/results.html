Learning and evaluation

What this demonstrates

The encoder learns a compact representation without labels; the classifier then uses labels to separate yes from no. Fine-tuning adapts that representation. Validation chooses the configuration and threshold; test metrics are reported after those choices. The group-safe random split supports team comparison, but it does not measure future-time generalization.

The call simulator keeps the AE1 base score fixed for each customer. Dialogue changes only the labeled simulation layer. Names and call reasons are fictional; features come from public dataset rows.
